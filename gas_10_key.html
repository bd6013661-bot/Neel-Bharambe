Gas 10-Problem Set: Worked Solutions

Each solution follows the 5-step routine: table → convert → pick equation → predict → solve/check. Red = common mistake. R = 0.08206 L·atm/(mol·K), STP = 273.15 K and 1 atm (22.414 L/mol).

1. P₁=755 mmHg V₁=5.00 L T₁=298.15 K | P₂=380. mmHg V₂=? T₂=258.15 K, n constant.
V₂ = V₁ × (P₁/P₂) × (T₂/T₁) = 5.00 × (755/380.) × (258.15/298.15) = 5.00 × 1.987 × 0.8658 = 8.60 L.
Pressure dropped by about half (×1.99 for V), but T dropped only 13% (×0.866). The pressure effect wins, so the balloon expands. Trick: write each change as a ratio factor and ask whether it should make V bigger or smaller.
2. n = 4.50/44.009 = 0.1023 mol; T = 310.15 K. P = nRT/V = (0.1023)(0.08206)(310.15)/2.00 = 1.30 atm.
3. Empirical: C 85.6/12.011 = 7.127, H 14.4/1.008 = 14.29 → 1 : 2.00 → CH₂ (14.027 g/mol).
m=0.802 g, V=0.354 L, T=373.15 K, P=752/760=0.9895 atm
𝓜 = mRT/(PV) = (0.802)(0.08206)(373.15)/[(0.9895)(0.354)] = 70.1 g/mol. k = 70.1/14.027 = 5.00 → C₅H₁₀.
Exam combo: % composition → empirical formula, gas data → 𝓜, then k = 𝓜/𝓜_emp.
4. n(He) = 2.00/4.0026 = 0.4997 mol; n(O₂) = 8.00/31.998 = 0.2500 mol. RT/V = (0.08206 × 298.15)/5.00 = 4.893 atm/mol.
P(He) = 0.4997 × 4.893 = 2.45 atm; P(O₂) = 0.2500 × 4.893 = 1.22 atm; P_tot = 3.67 atm. χ(He) = 0.4997/0.7497 = 0.667 (check: 0.667 × 3.67 = 2.45 ✓).
The partial pressure depends on MOLES, not grams: 8 g O₂ gives less pressure than 2 g He.
5. P(O₂) = 758 − 19.8 = 738.2 mm-Hg = 0.9713 atm; T = 295.15 K; V = 0.512 L.
n(O₂) = (0.9713)(0.512)/(0.08206 × 295.15) = 0.02053 mol → × (2 KClO₃/3 O₂) = 0.01369 mol → × 122.55 = 1.68 g KClO₃.
Two traps: forgetting to subtract the water vapor, and forgetting the 2:3 ratio.
6. n(N₂) = PV/RT = (1.10)(65.0)/(0.08206 × 298.15) = 2.922 mol → × (2/3) = 1.948 mol NaN₃ × 65.01 = 127 g NaN₃.
Pattern: gas → mol via PV=nRT, then mole ratio, then grams.
7. Same T and P → liters behave like moles. 6.00 L N₂ would need 18.0 L H₂, but only 15.0 L is available → H₂ limiting. NH₃ = 15.0 × (2/3) = 10.0 L. N₂ used = 15.0/3 = 5.00 L → 1.00 L N₂ left over.
8. n(Al) = 2.00/26.982 = 0.07412 mol (÷2 = 0.0371). n(Cl₂) = (1.00)(1.50)/(0.08206 × 298.15) = 0.06131 mol (÷3 = 0.0204) → Cl₂ is limiting.
AlCl₃ = 0.06131 × (2/3) = 0.04087 mol × 133.33 = 5.45 g AlCl₃.
9. (a) rate(H₂)/rate(O₂) = √(31.998/2.016) = 3.98× faster.
(b) rate(X)/rate(He) = √(𝓜_He/𝓜_X) → 0.354 = √(4.0026/𝓜) → 𝓜 = 4.0026/0.354² = 31.9 g/mol → O₂.
(c) Time is the inverse of rate: t_X/t_N₂ = √(𝓜_X/𝓜_N₂) → 𝓜 = 28.014 × (191/105)² = 92.7 g/mol.
Heavier gas = slower rate = LONGER time. Square both sides to solve for 𝓜.
10. u_rms = √(3RT/𝓜), R = 8.314 J/(mol·K), T = 298.15 K.
He: √(3 × 8.314 × 298.15/0.0040026) = 1.36 × 10³ m/s; Xe: √(3 × 8.314 × 298.15/0.13129) = 238 m/s.
(b) Equal speeds mean equal T/𝓜: T(O₂) = 298.15 × (31.998/4.0026) = 2.38 × 10³ K.
𝓜 in kg/mol (4.0026 g → 0.0040026 kg). With g/mol you'd get an answer √1000 ≈ 31.6× too small.
